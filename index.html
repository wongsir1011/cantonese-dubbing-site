Signal chain

五個站，一條訊號鏈

同錄音室嘅工序一樣：聲入嚟，逐站處理，最後配音出去。中間留返個校對站俾你把關。

01

拖檔入嚟

音檔或者影片拖入去。長片會自動切段送去轉錄。

02

轉錄分講者

Azure、ElevenLabs、Gemini 三揀一，普通話轉文字兼分開男女講者。

03

翻譯做粵語

AI 譯成廣東話口語，唔係硬繃繃嘅書面翻譯。五種語氣可揀。

04

你嚟校對

紅黃標記提你邊句未譯、邊句太書面。改啱先落一步。

05

合成配音

男女聲分開合成，對齊時間軸。影片仲會燒返繁體字幕。

STEP 1

下載 zip，解壓到一個資料夾。四個檔案要擺埋一齊。

STEP 2

雙擊 launch.bat（Windows）或 launch.command（Mac），瀏覽器自動開。

STEP 3

撳右上「設定」填 API 金鑰，跟住拖檔入去。使用說明書喺 zip 入面。

要準備

程式要 Python 3 同 ffmpeg 先行到（做 API 代理、影片合成、字幕燒錄）。Mac 通常已有 Python；ffmpeg 用 Homebrew 裝。Windows 兩樣都要裝，說明書有逐步教學。另外要自備 API 金鑰——Azure 有免費層，一個月做到約十五集節目。
